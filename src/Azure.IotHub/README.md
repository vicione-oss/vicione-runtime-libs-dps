# Azure Iot Hub DataPort [↩](./../../README.md)

DataPort für Azure Iot Hub

## Konfiguration - Verwendung

### Voraussetzungen

- Zugriff auf ein Azure Konto
- Zugriff auf ein Azure Abonnement

### Einrichtung

1. Gehen Sie zur Azure Website und melden Sie sich an.
2. Gehen Sie zum Produkt **IoT Hub**.
3. Erstellen Sie einen Iot Hub.
4. Gehen Sie zum neuen Iot Hub.
5. Gehen Sie auf die Übersichtseite
6. Unter **Hostname** steht die Adresse für den Hub.
7. Unter **Sicherheitseinstellungen** -> **Richtlinien für den gemeinsamen Zugriff** auswählen.
8. Klicken Sie auf **iothubowner**, das ist der **Shared Access Signature Key** Name.
9. Hier ist der Primary Key, der der **Shared Access Signature Key** ist.
