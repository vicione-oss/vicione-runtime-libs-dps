# Azure EventGrid Topic DataPort [↩](./../../README.md)

DataPort für Azure EventGrid Topic

## Konfiguration - Verwendung

### Voraussetzungen

- Zugriff auf ein Azure Konto
- Zugriff auf ein Azure Abonnement

### Einrichtung

1. Gehen Sie zur Azure Website und melden Sie sich an.
2. Gehen Sie zum Produkt **Event Grid**.
3. Gehen Sie auf der Event Grid Seite unter **Custom Events** zu Topic / Themen.
4. Erstellen Sie eine Topic
5. Gehen Sie zum neuen Topic
6. Gehen Sie auf die Übersichtseite
7. Unter **TopicEndpoint** steht die Adresse für das Topic.
8. Auf der Seite unter **Einstellungen** -> **Zugangsschlüssel** finden Sie den Zugangsschlüssel.
