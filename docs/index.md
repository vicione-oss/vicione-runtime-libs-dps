# ViciOne DataPort documentation

Documentation for the ViciOne Suite **DataPort** runtime library. The site is organized by area, each
mirroring the matching `src/` project — pick the one you need from the tabs above, or start here:

- [**DataPort**](DataPort/index.md) — the core framework: the communication object, the node model,
  channels, and the `LinkedNode` tree.
- [**DataPort.Extensions**](DataPort.Extensions/index.md) — reusable base classes for building incoming
  (read/poll) and outgoing (write) data ports, plus the generated API reference.
- [**DataPort.Extensions.Testing**](DataPort.Extensions.Testing/index.md) — test helpers: YAML
  schema-consistency tests and eventual-value assertions.
